# 🚀 How to Publish IconSearch to Penpot Official Plugin Registry

The IconSearch Penpot plugin is fully built, hosted, and live on production at `https://iconsearch.info/penpot/manifest.json`. Follow these simple steps to publish it to Penpot's official community marketplace!

---

## 🌐 1. Verify Your Hosted Production URLs

Your plugin is automatically hosted on your Vercel deployment:

- **Manifest URL**: `https://iconsearch.info/penpot/manifest.json`
- **Main Code**: `https://iconsearch.info/penpot/code.js`
- **UI Webview**: `https://iconsearch.info/penpot/index.html`
- **Icon**: `https://iconsearch.info/penpot/icon.png`

---

## 📝 2. Submit to Penpot Community Registry

Penpot features official plugins directly inside Penpot's **Plugins Manager** (`design.penpot.app`).

### Option A: Submit on Penpot Community Forum (Fastest)
1. Go to the [Penpot Community Plugins Category](https://community.penpot.app/c/plugins/13).
2. Click **+ New Topic**.
3. Fill in the details:
   - **Title**: `[Plugin] IconSearch - 355,000+ Vector Icons`
   - **Manifest URL**: `https://iconsearch.info/penpot/manifest.json`
   - **Description**: Search & insert 355,000+ vector SVG icons across Lucide, Heroicons, Tabler, Phosphor, Remix, Feather, Bootstrap, Material, and more directly into Penpot.
   - **Category**: Plugins / Integration

### Option B: Submit via Penpot Official GitHub Repository
1. Go to Penpot's main GitHub repository: [github.com/penpot/penpot](https://github.com/penpot/penpot).
2. Open an **Issue** or **Pull Request** with the tag `plugin-submission`.
3. Include your Manifest URL: `https://iconsearch.info/penpot/manifest.json`.

---

## 🎉 What Happens Next?
Once approved by the Penpot team, `IconSearch` will appear in the **Discover Plugins** section of Penpot for millions of designers worldwide! 🎨✨
