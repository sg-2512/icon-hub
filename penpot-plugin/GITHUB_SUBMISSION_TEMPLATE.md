IconSearch gives Penpot designers instant access to 355,000+ vector SVG icons across 20+ top libraries (Lucide, Heroicons, Tabler, Phosphor, Remix, Feather, Bootstrap, Ant Design, Material Design, Radix, Octicons, FontAwesome, and more).

- **1-Click Native Vector Import**: Inserts editable Penpot vector shape groups directly onto your active canvas.
- **Connect Screen FIRST**: Clean device code pairing authentication.
- **High-Contrast Dark Mode**: Crisp icon previews optimized for Penpot's dark theme.
- **Ultra-Fast 60 FPS Infinite Scroll**: Batched DOM pagination for buttery smooth scrolling through 355,000+ icons.
- **Live Color & Size Customizer**: Preset swatches + custom HEX color picker + size selector (16px to 128px).
